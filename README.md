# Qener Helper — облачный канал подписанных обновлений

Этот **отдельный публичный репозиторий** предназначен только для обычных Windows x64 ZIP-пакетов Qener Helper, подписанных новым ключом Ed25519 в защищенном GitHub Actions workflow.

- Исходники и автоматические тесты находятся в приватном репозитории `lexeer-source/qener-helper`.
- Старые установки используют старый канал `lexeer-source/qener-helper-releases`; переход на новый канал осуществляется через специальную сборку, **подписанную старым ключом**.
- Новый ключ применяется только после установки переходной сборки.
- В этом репозитории не хранятся исходники, пароли, служебные журналы, закрытые ключи или данные табелей.

Публикация нового релиза выполняется вручную после успешных офлайн-тестов, проверки ZIP/манифеста и криптографической подписи. До выпуска переходной сборки этот канал не используется установленными программами.
